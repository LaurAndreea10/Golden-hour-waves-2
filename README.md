# Golden Hour Waves 2 🌅🌊

Interactive ocean scene built with **HTML, CSS and Canvas JavaScript**.

Move the pointer to change the wind. Click or tap to create a splash.

## Preview

Golden Hour Waves 2 is a creative coding experiment with a cinematic sea atmosphere: warm sunset tones, moving waves, particles and a full day/night transition.

## Highlights

- 🌊 Procedural animated wave layers
- 🌅 Day → sunset → night → dawn color cycle
- ☀️ Dynamic sun and moon rendering
- ✨ Stars, clouds, birds and shimmer effects
- 🏄 Small surfer detail on the middle wave
- 💦 Click / tap splash interaction
- 🌬️ Pointer-controlled wind movement
- 🫧 Foam particles and night bioluminescence
- 📱 Responsive full-screen canvas
- ♿ Reduced-motion friendly hint animation

## Built With

- HTML5
- CSS3
- Canvas API
- Vanilla JavaScript
- GitHub Pages

## How It Works

The project uses a single full-screen canvas. JavaScript calculates multiple wave layers, blends color palettes over time and adds interactive impulses when the user clicks or taps the scene.

## Run Locally

```bash
git clone https://github.com/LaurAndreea10/Golden-hour-waves-2.git
cd Golden-hour-waves-2
```

Then open `index.html` in your browser.
